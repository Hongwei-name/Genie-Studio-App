## 🔧 如需中文界面

### 方法1：重新安装 Inno Setup

1. 卸载当前 Inno Setup
2. 重新下载安装：https://jrsoftware.org/isinfo.php
3. 安装时勾选 **"ChineseSimplified"** 语言包
4. 重新运行安装程序生成脚本

### 方法2：手动下载语言文件

1. 下载 ChineseSimplified.isl 文件
2. 放到 Inno Setup 安装目录的 Languages 文件夹
3. 重新运行安装程序生成脚本
