# zero_K-Genie

智元标注审核助手桌面端 - 解决并发能力不足及功能弱的问题

## 简介

zero_K-Genie 是一款基于 Flutter 开发的 Windows 桌面应用程序，用于智元标注审核工作。它提供了高效的并发处理能力和丰富的功能特性。

## 功能特性

- ✅ macOS 风格的现代化界面
- ✅ 任务管理和批量处理
- ✅ WebView 内嵌审核页面
- ✅ 实时统计和监控
- ✅ 本地配置管理
- ✅ 日志查看和错误追踪

## 技术栈

- **框架**: Flutter 3.12.2+
- **状态管理**: Riverpod
- **路由**: GoRouter
- **网络**: Dio
- **本地存储**: SharedPreferences
- **窗口管理**: window_manager

## 安装

### 从源码构建


## 新用户首次使用流程

第一次使用时，请严格按照“安装浏览器脚本 → 登录获取 Token → 保存配置”的顺序操作。脚本负责在智元标注平台页面中提供审核辅助功能，桌面端负责任务管理、统计和配置。

### 1. 启动应用并打开配置页面

1. 启动 `zero_K-Genie`。
2. 点击左侧导航栏的 **偏好设置**，进入配置页面。
3. 确认右上角显示应用状态。首次使用时 Token 为空是正常现象。

### 2. 一键安装脚本猫和审核脚本

1. 在配置页面找到 **浏览器脚本** 区域。
2. 点击 **一键安装**。
3. 应用会用系统默认浏览器打开脚本猫官网，以及当前版本的 `zero_K-Genie` 用户脚本安装页。
4. 在脚本猫官网按浏览器提示安装脚本猫扩展。浏览器出于安全原因需要用户手动确认扩展安装，应用无法静默安装浏览器扩展。
5. 回到用户脚本安装页，点击脚本猫提供的安装/确认按钮。
6. 打开脚本猫的脚本管理页面，确认 `zero_K-Genie Review Helper` 已启用。

脚本的匹配地址是智元标注平台页面。安装完成后，请不要在脚本猫中停用该脚本；后续脚本更新会通过元数据中的更新地址提示。

### 3. 登录智元平台并获取 Token

1. 回到应用配置页面，在 **认证** 区域点击 **点击登录获取 Cookie**。
2. 在弹出的登录页面中完成智元标注平台登录。
3. 登录成功后，应用会自动读取当前登录 Cookie，并填入 **Token (Cookie)** 输入框。
4. 确认 Token 已填入后点击 **保存配置**。
5. 保存成功后，右上角状态应显示 **已认证 · 运行中**。

Token 实际上是浏览器登录 Cookie，仅保存在本机配置存储中。不要把 Token 发送给他人，也不要提交到代码仓库或公开截图中。

### 4. 完成首次运行配置

建议首次使用保持以下设置：

- **EP 打开方式**：选择 **浏览器**，这样打开的智元平台页面会运行已安装的脚本猫脚本。
- **刷新频率**：保持默认值即可，数值越小请求越频繁；如遇平台限流可适当调大。
- **并发数**：先使用默认值，确认网络和账号稳定后再逐步调整。
- **自动打开新 EP**：根据工作习惯开启；不熟悉功能时建议先关闭，手动确认任务后再打开。

修改后点击 **保存配置**。应用启动时会自动运行本地服务，右上角显示 **本地服务在线** 即表示脚本与桌面端之间的通知通道已准备好。

### 5. 验证安装是否成功

1. 点击左侧 **工作台**，等待任务列表加载。
2. 手动打开一个待审核 EP，确认浏览器页面右侧或页面内出现 zero_K-Genie 脚本面板。
3. 在脚本面板中确认任务列表、验收失败筛选和统计功能可用。
4. 完成一次审核后回到应用，检查任务状态和 **数据统计** 页面是否更新。

如果页面没有出现脚本面板，先确认：脚本猫扩展已启用、`zero_K-Genie Review Helper` 已启用、当前页面地址属于智元平台，并刷新当前页面。

## 日常使用

- **工作台**：查看待审核任务和 EP，手动或自动打开审核页面。
- **失败 EP**：集中查看验收失败记录，并重新处理需要返工的 EP。
- **运行日志**：查看登录、刷新、任务处理和脚本通知等运行信息。
- **数据统计**：查看今日完成数量、视频时长等统计数据。
- **偏好设置**：调整刷新频率、并发数、初筛人筛选、EP 打开方式和脚本安装入口。

### 常见问题

| 问题 | 处理方式 |
| --- | --- |
| 点击“一键安装”后没有打开浏览器 | 检查 Windows 默认浏览器设置，然后重新点击。 |
| 脚本猫已安装但没有脚本面板 | 在脚本猫管理页启用脚本，确认页面地址为智元平台后刷新页面。 |
| Token 获取后仍显示未认证 | 点击“保存配置”，确认 Cookie 输入框不是空的；必要时重新登录获取。 |
| 任务列表没有刷新 | 检查右上角是否显示“本地服务在线”，并确认刷新没有被暂停。 |
| 视频或页面操作卡顿 | 优先使用系统浏览器打开 EP，并关闭不必要的浏览器标签页。 |
